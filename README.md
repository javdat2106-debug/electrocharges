# Feruza Charge

Предстартовый сайт проекта зарядной площадки для электромобилей в Ташкенте, Мирзо-Улугбекский район, ул. Феруза, 32А. На площадке запланированы две станции постоянного тока по 120 кВт, шесть разъёмов и фудтрак с окном выдачи.

## Что есть на сайте

- Панорама площадки на основе фотографии локации и отдельная визуализация фудтрака.
- Информация о станциях и ориентировочном времени зарядки.
- Адрес, встроенная карта Google и ссылка для построения маршрута.
- Адаптивная вёрстка, отдельный кадр для телефона и плавное появление блоков при прокрутке.

## Как открыть

Скачай `Feruza-Charge.html` и открой его в браузере. HTML, CSS, JavaScript и изображения собраны в одном файле. Для карты и маршрута нужен интернет.

## Публикация

Для размещения сайта на статическом хостинге сохрани копию `Feruza-Charge.html` под именем `index.html` и загрузи её в папку публикации. Сборка и установка зависимостей не требуются.

## Статус проекта

Кадры с зарядками и фудтраком показывают, как площадка может выглядеть после открытия. Загрузка станций на сайте демонстрационная. Форма проверяет заполнение полей, отправка заявок пока не подключена.
